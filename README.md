# ascend-site

Site vitrine public d'Ascend Intelligences — [ascendintelligences.com](https://ascendintelligences.com).

Page statique unique (`index.html`, bilingue EN/FR, auto-suffisante), servie par
GitHub Pages. Le domaine est déclaré dans `CNAME`.

**Ce dépôt est public : n'y placer que le contenu du site.** Les documents
d'entreprise (statuts, EIN, contrats, stratégie) restent dans le dépôt privé
séparé — jamais ici.

## Déploiement

Pousser sur `main` suffit : GitHub Pages republie la page. Le formulaire de
contact passe par Formspree ; aucune étape de build.
